DXF imports at the wrong size: how to find the unit and fix the scale

A DXF file is just numbers. A line from 0 to 100 can be 100 mm, 100 inches or 100 cm. Many files do not say which, and some say the wrong thing. The result is a part that comes into your laser or CAM software 25.4 times too small or too large.

Read the error factor

Part looksLikely cause
25.4× too smallDrawn in inches, read as millimetres
25.4× too bigDrawn in millimetres, read as inches
10× too small / bigCentimetres and millimetres mixed up
2.54× offInches and centimetres mixed up

Check what the file declares

Open the DXF in a text editor and search for $INSUNITS. The number on the second line after it is the unit code stored by the CAD program.

  9
$INSUNITS
 70
     4

Common codes: 1 inches, 2 feet, 4 millimetres, 5 centimetres, 6 metres, 0 unitless. If the header is missing or 0, the software has to guess, and the guess is often wrong. If it says 1 but you drew in millimetres, the file is mislabelled.

Fix it in the software you use

  • LightBurn: the DXF import settings include a unit choice and an auto-detect option. If auto-detect picks wrongly, turn it off and set the unit yourself (Edit → Settings → File Settings), then re-import.
  • Any program: import once, measure a dimension you know, and scale the result by the exact factor (25.4, 0.03937, 10 or 0.1). Check a second dimension afterwards.
  • In the CAD program: export again with the units set explicitly to millimetres.

Fix it before the file leaves your computer

DXF Preflight reads the declared unit, shows the part size in millimetres at the unit you choose, warns when the size is implausible (for example a bracket that is 2.5 m long), and exports a corrected DXF in millimetres. You can also force the overall width to a known value. It runs in your browser; the file is not uploaded.
